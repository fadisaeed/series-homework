# series-homework
פרויקט שעובד עם נתונים של סדרות טלוויזיה מתוך קובץ נתונים.

## איך מריצים את הפרויקט?

פותחים את הטרמינל בתיקייה של הפרויקט ומריצים:

`node check.js`

כדי ליצור קובץ חדש עם הנתונים המעודכנים, מריצים:

`node save-updated.js`

## שאלות

### 1. למה צריך להעתיק אובייקטים ומערכים מקוננים?

כי כשמעתיקים רק את האובייקט הראשי, המערכים והאובייקטים שבתוכו עדיין קשורים למקור. אם נשנה אותם, גם הנתונים המקוריים ישתנו. לכן צריך להעתיק גם את החלקים הפנימיים שרוצים לשנות.

### 2. למה העתקה שטחית לא פתרה את הבאג בפונקציה שמוסיפה פרק לעונה הראשונה?

כי העתקה שטחית מעתיקה רק את האובייקט החיצוני ולא את המערכים שבתוכו. כשמוסיפים פרק ישירות למערך, גם המערך המקורי משתנה. כדי למנוע את זה צריך ליצור עותקים חדשים של מערך העונות, העונה הראשונה ומערך הפרקים שלה.
